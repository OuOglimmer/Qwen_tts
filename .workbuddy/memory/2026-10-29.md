## 修正：下拉选项大小不统一（用户截图反馈）

用户原话：「选项的样式大小不统一，内部的盒子大小不是固定的。」

**根因不是 Select 组件，是 CSS 穿透**：`theme.css` 里 `.panel-heading span`（灰底胶囊，
globals 还叠加了 `float:right` + 15px 圆角）是**后代选择器**，而 `.xselect-panel` 虽用
`position:fixed` 视觉上跳出卡片，DOM 上仍是 `.panel-heading` 的子孙 —— 于是每个选项的文字 span
都被套成一个宽度随文字走的灰盒子。实测同一面板三行 span 宽度 164 / 182 / 182，行内还各自有
`padding:5px 9px`。

顺带发现第二个不一致：选项继承 `.panel-heading` 的 `font-weight:650`，而 `.is-selected` 写的是 600，
**选中的反而比未选中的细**；触发器的值 span 也被塞了内边距（暗色下不明显）。

### 改法（`app/theme.css`）

1. `.panel-heading .xselect span, .collapse .xselect span` → `float:none; padding:0; border-radius:0;
   background:transparent; color/font-weight/font-size:inherit`。作用域取 `.xselect` 而非
   `.xselect-panel`，把触发器的值 span 一起收干净。
2. `.xselect-panel { font-weight:400 }` 显式归零，选中态 600 才立得起来。
3. `.role-select .xselect-trigger { font-weight:500 }`：原来继承 650，一点开弹层看到 400 的选项，
   一开一合字重会跳。
4. `.xselect-option` 行高改为 **钉死 32px**（原 `padding:6px 9px` 随内容浮动），`Select.tsx` 的
   `ROW_H` 33 → 32 同步（面板高度按行数估算，不同步会算错翻上/翻下位置）。

### 复测数值

- 第 2、3 步：三行均 200×32、`weight` 依次 600/400/400、未选中 `bg` 透明；面板 220×106
  （= 3×32 + 上下 4px + 边框）；触发器 220×32，值 span `padding:0`、`bg` 透明。
- 全部声线页（`.asset-toolbar` 里的 Select，非标题栏内）行高同为 32、无灰盒，未被波及。
- 浅色 / 暗色 / 第 3 步三处截图确认；`npx tsc --noEmit` 通过。

## 修掉 models.psd1 里残留的 0.6B 兜底（用户："修复这个问题"）

- 背景：`.env` 已把 clone 指向 `voice_clone_1.7b`（从 `D:\QwenTTS_Packages` 分卷解出，
  sha256 与包内一致），但 `config/models.psd1` 仍写 0.6B。psd1 只在环境变量缺失时生效，
  一旦回落就等于换权重（enc_dim 1024 vs 2048，声线 prompt 直接失效）。
- 顺带查出一个更硬的 bug：`common.ps1` 原来无条件 `Join-Path $projectRoot $serviceConfig.ModelPath`。
  Join-Path 对绝对子路径是**字面拼接**，实测 `Join-Path 'D:\repo' 'D:/ouyang/model/x'`
  → `D:\repo\D:\ouyang\model\x`（不存在），后面 `Test-Path model.safetensors` 就误报
  "Model is incomplete or missing"。说明这个兜底分支一直是坏的，只是没人走过（都在用 .env）。
  改成先 `IsPathRooted` 再拼。
- **坑（重要）：Windows PowerShell 5.1 + 无 BOM 的 UTF-8 文件 = 按 cp936 解码**。
  先在 psd1 里加了中文注释，`Import-PowerShellDataFile` 直接报"无法分析为 PowerShell
  数据文件"；同样的中文写进 .ps1 则报"字符串缺少终止符"。同一文件换成 ASCII 注释立刻正常。
  **本项目的 .ps1 / .psd1 / .cmd 一律只写 ASCII**，中文解释放 .md 或 Python 注释里。
- 验证：把 common.ps1 第 12–23 行原文取出来 Invoke-Expression（不抄一份逻辑），
  env 已设置 / psd1 兜底 两种情况下四个组合都解析到 1.7B 且 `model.safetensors=True`。
- 遗留（未改，属历史文档）：`design/technical-overview.md:110`、
  `design/llm-application-review.md` 仍写着"当前部署 clone 用 0.6B"，已过时。
